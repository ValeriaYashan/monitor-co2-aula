# Registro de uso de IA

Plantilla para que cada estudiante o equipo documente cómo usó herramientas de IA al programar el panel o el análisis. El objetivo no es prohibir ni auditar, sino practicar un uso responsable: pedir con claridad, verificar y poder explicar el resultado.

Antes de abrir la herramienta, escribí con tus palabras qué querés lograr. Después completá una fila por cada intercambio importante.

| Fecha | Qué quería lograr (mis palabras) | Prompt que usé | Qué devolvió la IA (resumen) | Cómo lo verifiqué | Qué cambié yo y por qué |
|-------|----------------------------------|----------------|------------------------------|-------------------|--------------------------|
|       |                                  |                |                              |                   |                          |

## Lista de verificación antes de usar código generado

1. Lo leí completo y puedo explicar con mis palabras qué hace cada parte.
2. No contiene contraseñas, claves ni datos personales, y yo tampoco los pegué en el prompt.
3. Lo probé con datos cuyo resultado conozco de antemano (por ejemplo, un CSV de tres filas con valores que puedo calcular a mano).
4. Revisé unidades y umbrales: ppm, grados Celsius, minutos.
5. Lo probé con datos malos o vacíos y no se rompe sin avisar.
6. Anoté qué parte escribió la IA, qué parte escribí yo y qué parte corregí.

## Preguntas para la reflexión final

¿En qué momento la IA se equivocó o propuso algo que no servía? ¿Cómo lo detecté? ¿Qué habría pasado si no lo verificaba? ¿Qué aprendí sobre cómo pedir mejor?
