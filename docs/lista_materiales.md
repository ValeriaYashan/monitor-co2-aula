# Lista de materiales

Para un dispositivo (un grupo puede armar uno por aula medida).

| Cantidad | Componente | Notas |
|----------|------------|-------|
| 1 | ESP32 DevKit de 30 pines | Medidas de la caja pensadas para 55 x 28,5 mm |
| 1 | Sensor de CO2 SCD40 en placa breakout | Alimentación de 3,3 V, comunicación I2C |
| 3 | LED de 5 mm: verde, amarillo y rojo | Semáforo en la tapa |
| 3 | Resistencias de 220 Ω | Una por LED |
| 1 | Protoboard pequeña o cables soldados | Según el nivel del grupo |
| 8 | Cables dupont | Sensor y LEDs |
| 4 | Tornillos M3 x 10 mm autorroscantes | Para cerrar la tapa |
| 1 | Cable micro-USB de datos | Alimentación y programación |
| 1 | Filamento PETG o PLA | Unos 40 g para base y tapa |

Si tu placa tiene otro tamaño o el puerto USB en otra posición, ajustá los parámetros al inicio de `caja/caja.scad`.
